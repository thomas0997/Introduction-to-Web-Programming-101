How to Use

/* content-box — default, you rarely write this explicitly */
.element {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 10px solid navy;
  /* actual total width = 360px — wider than you set */
}

/* border-box — what most devs prefer */
.element {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 10px solid navy;
  /* actual total width = exactly 300px — predictable */
}

/* Common reset — apply border-box to everything */
* {
  box-sizing: border-box;
}

Most modern developers apply * { box-sizing: border-box; } as a global reset so that width: 300px always means exactly 300px on the page — no mental math needed.
