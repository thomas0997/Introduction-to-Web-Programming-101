Part 1 — Display Types

display: block

Each element starts on its own line and stretches the full available width.

display: block;
Block A
Block B
Block C

display: inline

Elements flow within text. No new line. Only as wide as their content. Width/height have no effect.

display: inline;
Inline A Inline B Inline C — all on one line

display: inline-block

Sits inline like text BUT you can set width and height like a block.

display: inline-block;
width: 130px;
height: 60px;

130×60

display: table / table-row / table-cell

Makes non-table elements behave like a table, row, and cell — without using <table> tags.

display: table;

display: table-cell;

display: list-item

Any element behaves like a <li> — adds a bullet marker automatically.

display: list-item;

List item B
List item C

display: none

Removes the element completely. No space left behind — like it was never there.

Part 2 — Positioning

position: static (default)

Every element is static by default. It sits exactly where normal document flow puts it. top/left/right/bottom have zero effect.

position: static; /* default — top/left do nothing */
Static — I sit exactly where flow puts me.

position: relative

Shifts the element from its normal position. The key: the original space is still reserved — other elements don't move to fill it. The striped box below shows where it would have been.

position: relative;
top: 20px;   /* shift 20px DOWN from its natural spot */
left: 40px;  /* shift 40px RIGHT from its natural spot */

↑ space still reserved here

Relative — shifted 20px down, 40px right

position: absolute

Placed at exact coordinates relative to its nearest positioned parent (any parent with position other than static). It is removed from flow entirely — other elements fill the space it vacated.

/* Parent must have: position: relative; */
.parent { position: relative; height: 180px; }

.child-1 { position: absolute; top: 16px; left: 16px; }
.child-2 { position: absolute; top: 16px; right: 16px; }
.child-3 { position: absolute; bottom: 16px; left: 50%; }
position: relative container
(the positioning reference)

position: fixed

Stays fixed to the browser viewport — it doesn't move when you scroll. See the blue banner in the bottom-right corner of this page.

position: fixed;
bottom: 20px;
right: 20px;
z-index: 999; /* stays on top */

👉 Scroll up and down on this page. The blue banner in the bottom-right corner never moves — that's position: fixed.
