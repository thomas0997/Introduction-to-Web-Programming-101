Image Maps — <map>, <area>, usemap

An image map lets you define clickable hotspot regions on a single image, each linking to a different URL. The orange dashed boxes below are overlays added purely to visualize the invisible hotspot areas — they are NOT part of a real image map.

How It Works — Code Breakdown

STEP 1 — <img> with usemap

The usemap attribute connects the image to a <map> element by name. The # is required.

<img
  src="zoo_map.jpg"
  alt="Zoo map"
  usemap="#zoo_map"
  width="600"
  height="360"
/>
STEP 2 — <map> element

The <map> element is invisible — it's just a container for hotspot definitions. Its name attribute must match the usemap value (without the #).

<map name="zoo_map">
  ...area elements go here...
</map>
STEP 3 — <area> elements

Each <area> defines one clickable hotspot region. It is a self-closing (empty) tag.

<area
  shape="rect"
  coords="30,30,190,150"
  href="lions.html"
  alt="Lions"
/>

<area
  shape="circle"
  coords="300,200,80"
  href="fountain.html"
  alt="Fountain"
/>

area Attributes Reference

AttributeWhat it does
shapeDefines the shape of the hotspot: rect, circle, or poly
coordsThe coordinates that define the boundaries of the shape (see below)
hrefThe URL the hotspot links to when clicked
altAlternate text for screen readers (required for accessibility)
targetWhere to open the link — e.g., _blank for new tab

Coordinates by Shape

Shapecoords formatExample
rect x1, y1, x2, y2 — top-left corner to bottom-right corner coords="30,30,190,150"
circle x, y, radius — center point + radius in pixels coords="300,200,80"
poly x1,y1, x2,y2, x3,y3, ... — a list of x,y pairs forming any polygon coords="10,20,50,5,90,20,70,60,30,60"

All coordinates are measured in pixels from the top-left corner of the image (0,0).
